## Summary The submission proposes GlobalGate, which rescales each attention head by a learned, input-independent sigmoid scalar (Section 2, Eq. 1: head'_h = σ(g_h)·head_h). It claims this "solves long-context reasoning," is "universal" across architectures, tasks and modalities, and "outperform[s] all existing methods on every benchmark" (Abstract, Section 4). The only evidence is Table 1: on the authors' own 200-question LongQA-Mini benchmark at 2k context, a vanilla Transformer reaches 61.0% and GlobalGate reaches 74.0%, both at 125M parameters, from a single run. ## Assessment All three reviewers recommend rejection as technically flawed (R1: 1, R2: 2, R3: 1, all confidence 5). Every central point they raise can be checked directly against the text, and I agree with them. These are not differences of taste. They are verifiable defects in the experimental protocol. **1. Confounded comparison (R1, R2, R3).** Section 3.1 states the baseline is trained for 1 epoch and GlobalGate for 5 epochs. The 13-point gap in Table 1 (61.0 vs 74.0) therefore cannot be attributed to the gating mechanism, since it is confounded with 5× more training. This defect alone invalidates the paper's single result. **2. Test-set tuning (R1, R2, R3).** Section 3.1: "we use the same 200 questions to select hyperparameters and to report results." No held-out evaluation exists, so 74.0% is an optimistically biased number. **3. No baselines (R1, R2, R3).** Section 3.2 says "We did not compare against other long-context methods because they are known to be worse." That is an assertion, not evidence. The claims of SOTA "on all benchmarks" and "outperforming all existing methods" rest on one self-authored dataset and one under-trained baseline. **4. Long context is never tested (R1, R2, R3).**…

Revision plan

  1. must Training-budget confound: the baseline gets 1 epoch and GlobalGate gets 5 (Section 3.1), so the 61.0 vs 74.0 gap in Table 1 does not isolate the method.
    → Retrain the baseline with identical epochs, compute, and tuning budget. Report GlobalGate vs. baseline under matched conditions, and include an ablation with the gate removed or fixed at σ(g_h)=1. R1, R2, R3
  2. must Hyperparameters are selected on the same 200 LongQA-Mini questions used for reporting (Section 3.1).
    → Create disjoint validation and test splits, or tune on a separate dataset. Report test results only once, after tuning is frozen, and document what was tuned and over what range. R1, R2, R3
  3. must No long-context baselines or standard benchmarks. Section 3.2 dismisses other methods as 'known to be worse' without evidence, and all experiments are at 2k context.
    → Evaluate on public long-context benchmarks (e.g., RULER, LongBench, needle-in-a-haystack, BABILong) at 8k–128k. Compare against established long-context and gated-attention methods. R1, R2, R3
  4. must Universal/SOTA claims ('solves long-context reasoning', 'any architecture, task and modality', 'Future work is unnecessary') far exceed one 125M text model at 2k on one dataset.
    → Scope the title, abstract, and conclusion down to what is tested. Remove unsupported universality and SOTA statements, and add a limitations section. R1, R2, R3
  5. should Single seed (seed 0) with n=200 and no uncertainty estimates (Table 1).
    → Run at least 3–5 seeds and report mean±std and confidence intervals, plus a significance test for the main comparison. R1, R2, R3
  6. should The mechanism is unexplained. Section 2 calls the effect 'self-evident', yet a static per-head scalar is input-independent and possibly absorbable into W_O.
    → Analyse the distributions of learned σ(g_h) across layers and heads, explain how a static gate yields context selection, test whether the gain survives when the scale is folded into W_O, and compare alternative gate… R1, R3
  7. should The related-work section consists only of Vaswani et al. (2017), so novelty relative to head pruning and gated attention cannot be judged.
    → Add a related-work section covering long-context attention, positional extrapolation, head pruning, and gated attention, and state precisely what GlobalGate adds. R1, R2
  8. could LongQA-Mini is author-written, with no construction, length, category, or contamination details (Section 3.1).
    → Document how the questions were created and validated, plus their length distributions and question types, and describe the contamination checks performed. R1, R2, R3
