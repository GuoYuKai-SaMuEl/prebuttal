The 13-point gap in Table 1 (61.0 vs 74.0) is therefore not attributable to the gate. No equal-budget baseline is reported. This alone invalidates the headline result. 2. *Tuning on the test set.* Section 3.1: "we use the same 200 questions to select hyperparameters and to report results." The 74.0% is an optimistically biased estimate. 3. *No statistical support.* One run (seed 0), n=200. One question is 0.5 points, and the binomial standard error near 70% is about 3 points, so a 95% interval on each number is roughly ±6.
