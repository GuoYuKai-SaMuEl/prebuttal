## Summary of the submission The paper makes the SSM parameters Δ, B and C functions of the input (Section 3.2), which turns S4 into a time-varying "selective" SSM (S6). Because a time-varying SSM can no longer be computed as a convolution, the authors add a hardware-aware fused scan that keeps the expanded (B, L, D, N) state out of HBM (Section 3.3). They also propose a homogeneous block that merges H3 with a gated MLP (Section 3.4, Figure 3). The architecture is evaluated on: - synthetic tasks (Tables 1, 2 and 11); - Pile language modeling: scaling laws from 125M to 1.3B (Figure 4, Table 12) and zero-shot evaluation up to 2.8B (Table 3); - DNA (Figure 5, Figure 6 / Table 13); - audio (Figure 7, Tables 4 and 5); - speed and memory (Figure 8, Table 15); - ablations (Tables 6–10). ## Consensus strengths (well supported) 1. **The mechanism is clearly motivated and directly validated.** Table 11 shows Mamba (74K parameters) at 100% induction-head accuracy from training length 2^8 up to 2^20. MHA variants fall to roughly 5–10% by 2^13–2^14 and run out of memory beyond that. H3 and Hyena drop to chance. All three reviewers credit this result. 2. **The ablations isolate selectivity convincingly.** - Table 6: S6 gives 8.95 perplexity in the H3 block and 8.69 in the Mamba block, against roughly 10.2–10.8 for every LTI layer. - Table 7: making Δ alone selective moves perplexity from 10.93 to 9.98; making Δ, B and C all selective reaches 8.71. - Table 10: increasing N helps substantially only when B and C are selective (9.73 → 8.71 at about 1% extra parameters).
