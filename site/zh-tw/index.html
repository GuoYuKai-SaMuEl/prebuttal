真實論文的範例

用 arXiv 上公開的論文完整跑一次，再對照它們真正的結果。非官方示範，並非論文作者撰寫或認可。

論文會議Prebuttal真實結果
Mamba，v1 → v2一輪修改，各跑三個 seedICLR 20247.22 → 7.33 /10被拒 → 改投 COLM 2024 錄取
Direct Preference OptimizationAC 估計 5NeurIPS 20234.33 /6錄取（oral）
GlobalGate虛構，刻意埋了缺陷ICLR1.33 /10—

Mamba 被拒的版本和修改後的版本分數幾乎沒變，v1 修改清單裡的每一項在 v2 都又被提出來，包括真正的 ICLR 審稿人一再追問的誤差範圍。看不出變化時，工具就會直接說「沒有變化」。這些論文很可能在模型的訓練資料裡，分數會偏高，請當成流程示範，不是準確度的證據。

為什麼不直接把論文貼給聊天機器人？

在同一段對話裡扮演三位審稿人，意見最後會收斂成一個折衷。

貼給聊天機器人Prebuttal
同一段對話扮演所有審稿人三位審稿人在獨立的情境下閱讀，可以各自用不同模型；意見分歧（σ）一定會列出來
沒有格式的意見會議自己的表單與分數：NeurIPS 1–6、ICLR 1–10、ICML 1–10、CVPR 1–5、ARR 的 Soundness / Excitement / Overall。其他會議一個 TOML 檔就能定義
長論文被略讀，表格變成敘述LaTeX 與 PDF 的表格逐格讀取，審稿意見會引用「Table 3 第 4 欄」
不知道哪句話是哪個模型說的每份審稿都標明後端與模型；每篇論文的執行紀錄都留著，改版之間可以比較

投稿前：直接退稿檢查

不用模型、不花錢、幾秒鐘。PDF、LaTeX 資料夾或 Overleaf 下載的原始碼 .zip 都可以。

# 隨附示範論文的實際輸出
$ prebuttal check paper.pdf --venue icml
ICML rules (8 pages, double-blind, requires Impact Statement)

[x] format     no "Impact Statement" section
                — the venue requires one
[x] leftovers  unresolved references (??) on page 2
[ok] PDF metadata has no author
[ok] no self-revealing links or citations
[ok] main text 2 of 8 pages
[ok] no hidden text

2 problems that can get the paper desk-rejected.
匿名
PDF 中繼資料裡的作者名字、第一頁的 e-mail、camera-ready 或 [preprint] 版本、致謝段落、自己的 GitHub 連結、「our previous work [12]」這類自我揭露的引用。
格式
正文超過頁數上限（含雙欄排版）；缺少 NeurIPS checklist、ICML impact statement、CVPR LLM usage statement 或 ARR limitations。
殘留
??、[?]、TODO，以及讀者看不到的隱藏文字。
放進 CI
發現退稿風險時結束碼為 6；也提供 GitHub Action，每次 push 都檢查。
  • NeurIPS 檢查清單
  • ICLR 檢查清單
  • ICML 檢查清單
  • ARR 檢查清單
  • CVPR 檢查清單

用你已經有的模型

啟動時自動偵測；每份報告都記錄是哪個模型寫了哪份審稿。

後端費用說明
agent-claude / agent-codex訂閱制，不需 API key兩者都登入時就是跨模型審稿
api-gemini免費額度最省事的第一把 key
api-openrouter:free 模型免費一把 key，數百個模型
api-openai / api-anthropic自備 key預設用中階模型
ollama免費、本機論文不會離開你的電腦
relay免費由你、你的 agent 的子代理或任何系統來回答
隱私。論文內容會送到你選的後端供應商，之後怎麼處理由該供應商的條款決定，不是本工具。免費額度通常以你的資料作為代價；未發表的論文請確認條款、改用付費方案，或用 ollama、relay 留在本機。
這是壓力測試，不是預言。分數尚未經過校準（與 OpenReview 真實評分的校準結果還沒發表），單次執行的分數變動多半是雜訊。
