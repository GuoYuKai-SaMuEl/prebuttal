在 Reviewer 2 出現之前，先回答他。

Prebuttal 是機器學習論文的投稿前壓力測試：三位個性不同、在完全獨立的情境下閱讀論文的 AI 審稿人，加上一位領域主席（AC），在真正的審稿人看到稿件之前，先交給你一份會議格式的審稿報告。

pip install prebuttal
▶ 看範例報告（英文） 直接退稿檢查 中文說明

為什麼不直接把論文貼給聊天機器人？

在同一段對話裡扮演三位審稿人，意見最後會收斂成一個溫吞的折衷。

三位審稿人，互不共享情境

每位審稿人都是獨立的呼叫或處理程序，有自己的角色與模型，結論真的會不同；意見分歧（σ）一定會列在報告裡。

真實的審稿表單

NeurIPS 1–6、ICLR 1–10、ICML 1–10、CVPR 1–5，以及 ARR 的 Soundness / Excitement / Overall，附官方的分數說明。其他會議或期刊，一個 TOML 檔就能定義。

表格逐格讀取

解析 LaTeX，或依座標從 PDF 擷取表格，審稿人引用的是你的「Table 3 第 4 欄」，不是猜出來的數字。

修改清單，不只是分數

AC 把所有意見整理成 must / should / could 的修改清單；改完重跑，prebuttal diff 會告訴你哪些問題還在、哪些不見了。

投稿前：直接退稿檢查

不用模型、不花錢、幾秒鐘：匿名資訊外洩、會議的頁數上限與必要章節，以及殘留的 ??、TODO 或隱藏文字。

# 用 Overleaf 的 Menu → Download → Source 下載的 .zip 也可以直接檢查
$ prebuttal check paper.pdf --venue cvpr
$ prebuttal check paper.zip --venue cvpr
$ prebuttal check ./latex-src/ --venue iclr

匿名

PDF 中繼資料裡的作者名字、第一頁的 e-mail、camera-ready 或 [preprint] 版本、致謝段落、自己的 GitHub 連結、「our previous work [12]」這類自我揭露的引用。

格式與殘留

正文超過頁數上限（含雙欄排版）、缺少 NeurIPS checklist / ICML impact statement / CVPR LLM usage statement / ARR limitations，??、[?]、TODO。LaTeX 專案不需編譯；也提供 GitHub Action，每次 push 都檢查。

用你已經有的模型

啟動時自動偵測；每份報告都記錄是哪個模型寫了哪份審稿。

後端費用說明
agent-claude / agent-codex訂閱制，不需 API key兩者都有時就是跨模型審稿
api-gemini免費額度最省事的第一把 key
api-openrouter:free 模型免費一把 key，數百個模型
api-openai / api-anthropic自備 key預設用中階模型
ollama免費、本機未發表的論文不會離開你的電腦
relay免費由你、你的 agent 的子代理或任何系統來回答
隱私：論文內容會送到你選的後端供應商，之後怎麼處理由該供應商的條款決定，不是本工具。免費額度通常以你的資料作為代價；未發表的論文請確認條款、改用付費方案，或用 ollama、relay 留在本機。
這是壓力測試，不是預言：分數尚未經過校準（與 OpenReview 真實評分的校準結果還沒發表），單次執行的分數變動多半是雜訊。工具輸出與審稿表單都是英文。
