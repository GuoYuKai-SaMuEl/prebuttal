CVPR 2027 submission checklist

A desk-reject pre-flight for CVPR: the page limit, required sections, anonymity and leftovers — checked in seconds, with no model and no cost.

pip install prebuttal
prebuttal check paper.pdf --venue cvpr       # the PDF you will upload
prebuttal check paper.zip --venue cvpr       # Overleaf: Menu → Download → Source

What the check holds a CVPR paper to

  • Main text within 8 pages. The count stops at the first of LLM Usage Statement, References, Bibliography; two-column layouts are read column by column. Over the limit is a desk reject. Checked on the PDF (a LaTeX project needs compiling first).
  • A “LLM Usage Statement” section. The call requires it; the check looks for a heading with that name.
  • Anonymity (double-blind): no author name in the PDF metadata, no e-mail address on page 1, not the template's camera-ready or preprint build, no acknowledgements section, no links to your own repository, no “our previous work [12]”.
  • Leftovers: unresolved ?? references, [?] citations, TODO / FIXME, and text hidden from human readers (white or tiny text — venues have desk-rejected papers for hidden instructions to reviewers).

Only the references and the LLM Usage Statement may run past the 8 pages.

Rules taken from https://cvpr.thecvf.com/Conferences/2027/AuthorGuidelines. They change every year — confirm against this year's call. Anything the check flags as an error makes prebuttal check exit with code 6, so it can fail a CI job (see the GitHub Action).

The CVPR review form

Besides the scores, every review answers:

  • Summary
  • Strengths
  • Weaknesses
  • Suggestions
  • Justification for the rating

Rating 1–5

1Reject
2Weak reject
3Borderline
4Weak accept
5Strong accept

Confidence 1–5

1My best guess
2Willing to defend, but not sure
3Fairly confident
4Confident but not absolutely certain
5Absolutely certain

What will reviewers raise?

The checklist catches what gets a paper rejected unread. To see what reviewers will say about the paper itself, run three independent AI reviewers and an area chair on this form:

prebuttal run paper.pdf --venue cvpr

See a sample report, or read the guide. Other venues: NeurIPS · ICLR · ICML · ACL Rolling Review.
