ICML 2026 submission checklist

A desk-reject pre-flight for ICML: the page limit, required sections, anonymity and leftovers — checked in seconds, with no model and no cost.

pip install prebuttal
prebuttal check paper.pdf --venue icml       # the PDF you will upload
prebuttal check paper.zip --venue icml       # Overleaf: Menu → Download → Source

What the check holds a ICML paper to

  • Main text within 8 pages. The count stops at the first of References, Impact Statement, Acknowledgements, Acknowledgments; two-column layouts are read column by column. Over the limit is a desk reject. Checked on the PDF (a LaTeX project needs compiling first).
  • A “Impact Statement” section. The call requires it; the check looks for a heading with that name.
  • Anonymity (double-blind): no author name in the PDF metadata, no e-mail address on page 1, not the template's camera-ready or preprint build, no acknowledgements section, no links to your own repository, no “our previous work [12]”.
  • Leftovers: unresolved ?? references, [?] citations, TODO / FIXME, and text hidden from human readers (white or tiny text — venues have desk-rejected papers for hidden instructions to reviewers).

ICML asks for an Impact Statement after the main text; it does not count toward the page limit.

Rules taken from https://icml.cc/Conferences/2026/CallForPapers. They change every year — confirm against this year's call. Anything the check flags as an error makes prebuttal check exit with code 6, so it can fail a CI job (see the GitHub Action).

The ICML review form

Besides the scores, every review answers:

  • Summary
  • Strengths
  • Weaknesses
  • Questions to the Authors
  • Suggestions and Typos

Rating 1–10

1Trivial or wrong
2Trivial or wrong
3Clear reject
4Reject — not good enough
5Marginally below publication threshold
6Marginally above publication threshold
7Accept — good paper
8Accept — top 50% of accepted papers
9Strong accept — top 15%
10Award quality

Confidence 1–5

1My best guess
2Willing to defend, but not sure
3Fairly confident
4Confident but not absolutely certain
5Absolutely certain

What will reviewers raise?

The checklist catches what gets a paper rejected unread. To see what reviewers will say about the paper itself, run three independent AI reviewers and an area chair on this form:

prebuttal run paper.pdf --venue icml
