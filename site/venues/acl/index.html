ACL Rolling Review submission checklist

A desk-reject pre-flight for ACL Rolling Review: the page limit, required sections, anonymity and leftovers — checked in seconds, with no model and no cost.

pip install prebuttal
prebuttal check paper.pdf --venue acl       # the PDF you will upload
prebuttal check paper.zip --venue acl       # Overleaf: Menu → Download → Source

What the check holds a ACL Rolling Review paper to

  • Main text within 8 pages. The count stops at the first of References, Limitations, Ethics Statement, Acknowledgments; two-column layouts are read column by column. Over the limit is a desk reject. Checked on the PDF (a LaTeX project needs compiling first).
  • A “Limitations” section. The call requires it; the check looks for a heading with that name.
  • Anonymity (double-blind): no author name in the PDF metadata, no e-mail address on page 1, not the template's camera-ready or preprint build, no acknowledgements section, no links to your own repository, no “our previous work [12]”.
  • Leftovers: unresolved ?? references, [?] citations, TODO / FIXME, and text hidden from human readers (white or tiny text — venues have desk-rejected papers for hidden instructions to reviewers).

The limit is for long papers; short papers get 4 pages. ARR desk-rejects submissions without a Limitations section.

Rules taken from https://aclrollingreview.org/cfp. They change every year — confirm against this year's call. Anything the check flags as an error makes prebuttal check exit with code 6, so it can fail a CI job (see the GitHub Action).

The ACL Rolling Review review form

Besides the scores, every review answers:

  • Paper Summary
  • Summary of Strengths
  • Summary of Weaknesses
  • Comments, Suggestions and Typos

Soundness 1–5, half-steps allowed

1Major issues — not sufficiently thorough
2Poor — some main claims not sufficiently supported
3Acceptable — sufficient support for main claims
4Strong — sufficient support for all claims
5Excellent — one of the most thorough studies of its type

Excitement 1–5, half-steps allowed

1Not exciting
2Potentially interesting
3Interesting
4Exciting
5Highly exciting

Overall Assessment 1–5, half-steps allowed

1Do not resubmit
2Resubmit next cycle — needs substantial revisions
3Findings — accept to Findings of the ACL
4Conference — accept to an *ACL conference
5Consider for award

Reviewer Confidence 1–5

1My best guess
2Willing to defend, but not sure
3Fairly confident
4Confident but not absolutely certain
5Absolutely certain

What will reviewers raise?

The checklist catches what gets a paper rejected unread. To see what reviewers will say about the paper itself, run three independent AI reviewers and an area chair on this form:

prebuttal run paper.pdf --venue acl
