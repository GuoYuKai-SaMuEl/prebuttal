用 arXiv 上公开的论文完整运行一次，再对照它们真实的结果。非官方示例，并非论文作者撰写或认可。

Mamba 被拒的版本和修改后的版本分数几乎没变，v1 修改清单里的每一项在 v2 中都再次被提出，包括真正的 ICLR 审稿人反复追问的误差范围。看不出变化时，工具会直接说“没有变化”。这些论文很可能在模型的训练数据里，分数会偏高，请当作流程示例，而不是准确度的证据。

为什么不直接把论文丢给聊天机器人？

在同一个对话里扮演三位审稿人，意见最后会收敛成一个折中。

丢给聊天机器人Prebuttal
同一个对话扮演所有审稿人三位审稿人在独立的上下文中阅读，可以各自使用不同模型；意见分歧（σ）一定会列出来
没有格式的意见会议自己的审稿表和分数：NeurIPS 1–6、ICLR 1–10、ICML 1–10、CVPR 1–5、ARR 的 Soundness / Excitement / Overall。其他会议一个 TOML 文件就能定义
长论文被略读，表格变成叙述LaTeX 和 PDF 的表格逐格读取，审稿意见会引用“Table 3 第 4 列”
不知道哪句话出自哪个模型每份审稿意见都标明后端和模型；每篇论文的运行记录都会保留，版本之间可以对比

投稿前：直接拒稿检查

无需模型、不花钱、几秒钟。PDF、LaTeX 文件夹或 Overleaf 下载的源码 .zip 都可以。

# 随附示例论文的实际输出
$ prebuttal check paper.pdf --venue icml
ICML rules (8 pages, double-blind, requires Impact Statement)

[x] format     no "Impact Statement" section
                — the venue requires one
[x] leftovers  unresolved references (??) on page 2
[ok] PDF metadata has no author
[ok] no self-revealing links or citations
[ok] main text 2 of 8 pages
[ok] no hidden text

2 problems that can get the paper desk-rejected.
匿名
PDF 元数据里的作者姓名、第一页的邮箱、camera-ready 或 [preprint] 版本、致谢部分、自己的 GitHub 链接、“our previous work [12]”这类暴露身份的引用。
格式
正文超过页数限制（包括双栏排版）；缺少 NeurIPS checklist、ICML impact statement、CVPR LLM usage statement 或 ARR limitations。
残留
??、[?]、TODO，以及读者看不到的隐藏文字。
放进 CI
发现拒稿风险时退出码为 6；也提供 GitHub Action，每次 push 都检查。

用你已有的模型

启动时自动检测；每份报告都记录了哪个模型写了哪份审稿意见。

后端费用说明
agent-claude / agent-codex订阅制，无需 API key两者都登录时就是跨模型审稿
api-gemini免费额度最省事的第一个 key
api-openrouter:free 模型免费一个 key，数百个模型
api-openai / api-anthropic自带 key默认使用中档模型
ollama免费、本地论文不会离开你的电脑
relay免费由你、你的 agent 的子代理或任何系统来回答
隐私。论文内容会发送给你选择的后端服务商，之后如何处理由该服务商的条款决定，而不是本工具。免费额度通常以你的数据为代价；未发表的论文请先确认条款、改用付费方案，或用 ollama、relay 留在本地。
这是压力测试，不是预测。分数尚未校准（与 OpenReview 真实评分的校准结果还没有发布），单次运行的分数波动多半是噪声。
