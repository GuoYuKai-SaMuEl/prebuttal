在 Reviewer 2 出现之前，先回应他。

Prebuttal 是机器学习论文的投稿前压力测试：三位风格不同、在完全独立的上下文中阅读论文的 AI 审稿人，加上一位领域主席（AC），在真正的审稿人看到稿件之前，先给你一份会议格式的审稿报告。

pip install prebuttal
▶ 查看示例报告（英文） 直接拒稿检查 中文文档

为什么不直接把论文丢给聊天机器人？

在同一个对话里扮演三位审稿人，意见最后会收敛成一个不痛不痒的折中。

三位审稿人，互不共享上下文

每位审稿人都是独立的调用或进程，有自己的角色和模型，结论确实会不同；意见分歧（σ）一定会写进报告。

真实的审稿表

NeurIPS 1–6、ICLR 1–10、ICML 1–10、CVPR 1–5，以及 ARR 的 Soundness / Excitement / Overall，附官方的评分说明。其他会议或期刊，一个 TOML 文件就能定义。

表格逐格读取

解析 LaTeX，或按坐标从 PDF 提取表格，审稿人引用的是你的“Table 3 第 4 列”，而不是猜出来的数字。

修改清单，不只是分数

AC 把所有意见整理成 must / should / could 的修改清单；改完重跑，prebuttal diff 会告诉你哪些问题还在、哪些已经解决。

投稿前：直接拒稿检查

无需模型、不花钱、几秒钟：匿名信息泄露、会议的页数限制和必需章节，以及残留的 ??、TODO 或隐藏文字。

# Overleaf 的 Menu → Download → Source 下载的 .zip 也可以直接检查
$ prebuttal check paper.pdf --venue cvpr
$ prebuttal check paper.zip --venue cvpr
$ prebuttal check ./latex-src/ --venue iclr

匿名

PDF 元数据里的作者姓名、第一页的邮箱、camera-ready 或 [preprint] 版本、致谢部分、自己的 GitHub 链接、“our previous work [12]”这类暴露身份的引用。

格式与残留

正文超过页数限制（包括双栏排版）、缺少 NeurIPS checklist / ICML impact statement / CVPR LLM usage statement / ARR limitations，??、[?]、TODO。LaTeX 项目无需编译；也提供 GitHub Action，每次 push 都检查。

用你已有的模型

启动时自动检测；每份报告都记录了哪个模型写了哪份审稿意见。

后端费用说明
agent-claude / agent-codex订阅制，无需 API key两者都有时就是跨模型审稿
api-gemini免费额度最省事的第一个 key
api-openrouter:free 模型免费一个 key，数百个模型
api-openai / api-anthropic自带 key默认使用中档模型
ollama免费、本地未发表的论文不会离开你的电脑
relay免费由你、你的 agent 的子代理或任何系统来回答
隐私：论文内容会发送给你选择的后端服务商，之后如何处理由该服务商的条款决定，而不是本工具。免费额度通常以你的数据为代价；未发表的论文请先确认条款、改用付费方案，或用 ollama、relay 留在本地。
这是压力测试，不是预测：分数尚未校准（与 OpenReview 真实评分的校准结果还没有发布），单次运行的分数波动多半是噪声。工具输出和审稿表都是英文。
